Single-process Node.js application rooted at `server.js`, which bootstraps Express, Socket.io (attached to the same HTTP server), CORS, JSON parsing, static uploads, and an error-handling middleware. Routes are split by domain under `routes/` (auth, users, leads, contacts, orders, menu, todos, paysip, analytics, template, whatsapp) and mounted on `/api/*` prefixes; each route file is a plain `express.Router`. Data persistence uses Mongoose models under `models/` (User, Lead, Contact, Order, Template, etc.), with schemas declaring types, defaults, enums, and model-level helpers (`hashPassword`, `verifyPassword`). External integrations live in `utils/`: `metaTemplateService.js` and `whatsappService.js` wrap Facebook Graph API calls via axios, `cloudinaryService.js` handles image upload, and `conversationFlow.js` / `zestEatAutomationBot.js` implement bot logic. A global cron job (node-cron) runs every minute to dispatch scheduled templates via `runScheduledTemplates` from `routes/template`. Configuration is loaded from `.env` (MongoDB URI, JWT secret, port). The module exports `{ app, server, io }` so the parent process can attach additional listeners.
