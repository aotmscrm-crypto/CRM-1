Dev server runs via `npm run dev` (Vite) and proxies `/api` requests to `http://127.0.0.1:8000`; production builds with `npm run build` and previews with `npm run preview`. The backend base URL can be overridden at build time through the `VITE_API_BASE_URL` env variable (defaulting to `http://localhost:5000` locally and `https://crm-1-62pl.onrender.com` in production). Linting runs via `npm run lint` using ESLint 10 with React hooks and refresh plugins.
