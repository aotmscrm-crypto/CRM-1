Two sibling applications share a single repository: the `frontend/` SPA (React + Vite) consumes REST endpoints exposed by the `backend/` server, while real-time broadcast between dashboard users is handled via Socket.io on the same backend. The two sides communicate over HTTP/WebSocket — there is no shared code or build step between them — so cross-child coordination lives in the API contract (route paths, request/response shapes) and in deployment configuration not visible here. Loose assets at the root (`Hackathon.jpeg`, WhatsApp template chart doc) are project collateral rather than runtime artifacts.
